⚙️ הגדרה ראשונית — נדרשת פעם אחת בלבד

  1. היכנס ל-Google Cloud Console
  2. צור פרויקט חדש (או בחר פרויקט קיים)
  3. הפעל את Google Sheets API: לחץ כאן → Enable
  4. חזור ל-Credentials → Create Credentials → API Key → העתק את ה-Key
  5. פתח את הגיליון שלך → Share → "Anyone with the link" → Viewer
  6. הדבק את ה-API Key למטה ולחץ "רענן נתונים"
